# how-to-tell

Skill de agente (Claude Code e compatíveis) para **contar uma história em roteiro de vídeo curto de
produto ou de venda**, de 30 s a 2 min, com ou sem narração, feito de gravação real de tela.

Ela obriga início, meio e fim (um caso só, do pedido até o trabalho feito), põe o cliente como herói e
o produto como mentor dentro da cadeia de causa, e passa o roteiro por 36 perguntas e 21 modos de falha.
Traz também o portão da publicidade da advocacia no Brasil (Provimento 205/2021 da OAB), para quem vende
software a advogados.

Em português (pt-BR).

## Instalar

```bash
npx skills add grgbrasil/how-to-tell
```

## Conteúdo

- `skills/how-to-tell/SKILL.md`: a skill.
- `skills/how-to-tell/references/pesquisa.md`: o relatório que a fundamenta (livros de estrutura
  narrativa, meta-análises de persuasão narrativa, teses, guias de criativo do Google/Meta/TikTok,
  fontes práticas em português e o texto da OAB), com links e grau de confiança.
- `skills/how-to-tell/references/notas/`: as notas brutas das cinco frentes de pesquisa.
